# Claude.ai Project kurulumu

🇬🇧 [English](README.md) · 🇹🇷 Türkçe

1. claude.ai → **Projects → New project**.
2. **Set project instructions** kutusuna `project-instructions.md` içeriğini yapıştır.
3. **Project knowledge** alanına sadece sık başvurulan, kısa dosyaları ekle (mimari özeti, API şeması). Tüm repoyu yükleme: her mesajda bağlamı şişirir.
4. Konu değişince **yeni sohbet** aç; uzayan sohbette `compact-ctx` istemini kullan (`template/.claude/commands/compact-ctx.md`).

> Not: Claude.ai Projects `.claude/` klasörünü okumaz. O klasör Claude Code içindir. Claude.ai'da yalnızca bu talimat metni kullanılır.
